## Project Overview
This repository contains the Portfolio of Evidence for WEDE5020. The project is a website built for **Gift of the Givers Foundation**, South Africa's largest disaster response NGO, founded in 1992 by Dr Imtiaz Sooliman. The site showcases the organisation's history, mission, services, and provides visitors with a way to enquire about volunteering, sponsorship, or general contact.

The project is being developed across three parts:
- **Part 1 (current):** HTML structure, project planning, and content research.
- **Part 2:** CSS styling and responsive design.
- **Part 3:** JavaScript functionality and interactivity.

## Website Goals and Objectives
- Clearly communicate the organisation's mission, history, and impact to build donor trust.
- Make it easy for visitors to donate, volunteer, or request assistance.
- Provide a simple, mobile-friendly way to contact regional offices.

## Key Features and Functionality
- Responsive navigation menu with mobile toggle and logo.
- Five core pages: Home, About Us, Services, Enquiry, Contact.
- Enquiry form allowing visitors to register interest as a volunteer or sponsor.
- Contact page with two office locations and embedded maps.
- Basic client-side form validation (JavaScript).
